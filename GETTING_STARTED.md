# Getting Started - For Team Members

This guide will help you set up the project after cloning from GitHub.

## Prerequisites

Before you start, make sure you have these installed:

1. **Node.js** (version 18 or higher)
   - Download from: https://nodejs.org/
   - Check your version: `node --version`

2. **npm** (comes with Node.js)
   - Check your version: `npm --version`

3. **Git**
   - Download from: https://git-scm.com/
   - Check your version: `git --version`

## Setup Steps

### 1. Clone the Repository

```bash
git clone https://github.com/Hassan-Shahid123/event-management-system.git
cd event-management-system
```

### 2. Switch to Development Branch (if needed)

```bash
git checkout dev
```

### 3. Install Dependencies

```bash
npm install
```

This will install:
- `sql.js` - SQLite database (pure JavaScript, no native compilation needed)
- `typescript` - TypeScript compiler
- `jest` - Testing framework
- Other development dependencies

**Note**: Unlike `better-sqlite3`, `sql.js` doesn't require Visual Studio Build Tools or Python, so installation should work on any system without additional setup!

### 4. Build the Project

```bash
npm run build
```

This compiles TypeScript files from `src/` to JavaScript in `dist/`.

### 5. Run the Test

```bash
node dist/test.js
```

You should see:
```
✅ All tests passed!
```

## Available Scripts

- `npm run build` - Compile TypeScript to JavaScript
- `npm test` - Run tests (when tests are added)

## Troubleshooting

### Issue: `npm install` fails

**Solution 1**: Clear npm cache and retry
```bash
npm cache clean --force
npm install
```

**Solution 2**: Delete `node_modules` and `package-lock.json`, then reinstall
```bash
rm -rf node_modules package-lock.json  # On Windows: rmdir /s node_modules, del package-lock.json
npm install
```

### Issue: Build fails with TypeScript errors

**Solution**: Make sure you have the latest dependencies
```bash
npm install
npm run build
```

### Issue: Module not found errors

**Solution**: Rebuild the project
```bash
npm run build
```

## What Files Should Be Committed?

**DO commit** ✅:
- `src/` - Source code
- `package.json` - Dependencies list
- `tsconfig.json` - TypeScript config
- `.gitignore` - Git ignore rules
- Documentation files (README.md, SETUP.md, etc.)

**DON'T commit** ❌:
- `node_modules/` - Dependencies (huge, regenerated by `npm install`)
- `dist/` - Build output (regenerated by `npm run build`)
- `*.db` - Database files (contains local data)
- `package-lock.json` - Can cause conflicts (optional to exclude)
